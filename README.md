# 📊 ConnectaTel Customer Analysis

## 🔍 Project Overview
This project analyzes customer behavior for a telecommunications company (ConnectaTel) to identify usage patterns, understand user segmentation, and generate insights that can support business decisions such as pricing optimization and customer retention.

---

## 🎯 Business Objective
The goal of this analysis is to explore customer usage data and uncover patterns that help answer key business questions:
- Which users generate the most value?
- Are current plans aligned with customer behavior?
- What opportunities exist to improve retention and revenue?

---

## 🛠 Tools & Technologies
- Python (Pandas, NumPy)
- Data Visualization (Matplotlib, Seaborn)
- Jupyter Notebook
- Excel / CSV datasets

---

## 📂 Dataset
The dataset includes customer-level information such as:
- Call minutes
- Messages sent
- Data usage
- Plan type
- Monthly charges

---

## 📈 Analysis Process
1. Data loading and exploration  
2. Data cleaning and preprocessing  
3. Exploratory Data Analysis (EDA)  
4. Visualization of key variables  
5. Identification of patterns and trends  

---

## 💡 Key Insights
- High-usage customers tend to cluster within specific plans, suggesting opportunities for targeted pricing strategies.
- Some plans appear underutilized, indicating potential inefficiencies in current offerings.
- User behavior varies significantly, highlighting the importance of segmentation.

---

## 🚀 Recommendations
- Optimize pricing tiers based on actual usage patterns  
- Develop retention strategies for high-value customers  
- Reevaluate underperforming plans to better match user needs
